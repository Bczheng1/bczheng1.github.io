可以看到，vin是一个CTXIn数组，vout是一个CTxOut数组。

为什么要用数组？因为这样可以指明多笔交易，不可能像我之前那样，一个tx下只有一个vin out。因为比如吧你要花费多少钱，需要多个vin合成，几乎不可能刚刚好，vout也是，需要找零给自己。

这里大概的意思是，vin代表付款方，vout代表收款方。

但是付款方钱是哪里来的呢？这个网络并没有余额计算存储，都是记帐簿的形式。就是vin会定位到你这个账号上一笔vout，关于你的vout，用这个来支付，然后把这个vout给划掉，如果系统没划掉的，即在所有的vin中没有这个定位，那表明笔vout是未花费的。所以这里很巧妙，vout可以是你的收入，又可以变成你对别人的输出。其实按自然来理解，也正常，你花的钱肯定是你挣来的钱。

我们来具体来看一下CTXin和CTXOut这两个 类 的结构，这其中涉及到一些，vin定位到一笔out,你怎么证明这笔钱是你的，万一你用的是别人的钱怎么办？

这其中都会在CTxIn里面解决，以及一些必要的验证信息。

CoutPoint里的hash指向的就是某笔txid，就是CTransaction里调用GetHash方法得到的值，有了这个值，我们就可以找到具体是哪笔交易，然后n就表示是这笔交易的第几个vout,你可以看作是vout[n].

某年某月，你打工挣了一笔钱，这笔钱就是你的收入，别人给你的vout.

现在你要用这笔钱了，要放在vin里用来支付，所以vin里就定位到你这笔vout。然后经过查找，发现这笔vout从来没被引用过，也就是未花费，再经过签名验证，证明你这笔vout的钱是你所属。这样这笔交易就成立了。这之后，这笔vout在vin里可以查到，就被称为已花费的vout。

好，接下来说一下CScript scriptSig;这个存储数字签名以及验证相关，这里我们先简单把它当成账号来使用，因为这里如果开始讲，涉及的篇幅又会很大，放在以后再说。

重载函数的时候没问题，但vin,vout变成你自己定义的类后，这个函数，是得调用你类自身的Serialize函数，所以我们得像CTransaction一样，给类添加自身对序列化的支持，步骤一样的，如果你的vin下级还有自定义的类，也同样重复这个过程，直到遇到基础类型。它就能调用对应干活的那个Serialize重载函数进行序列化。

所以我们得把所有要序列化的自定义类，都加上下面这个：

  2.     (
  3.     READWRITE(vin);
  4.     READWRITE(vout);
  5.     )

5.CFlatData

但是我们看到源码中，COutPoint跟其他的不同，是这样一句代码：

IMPLEMENT_SERIALIZE(READWRITE(FLATDATA(*this)); )
cpp
运行

直接用对象*this做READWRITE的参数。然后将其转换为CFlatData类型，CFlatData代码如下：

  1. #define FLATDATA(obj)   REF(CFlatData((char*)&(obj), (char*)&(obj) + sizeof(obj)))
  2. class CFlatData
  3. {
  4. protected:
  5.     char* pbegin;
  6.     char* pend;
  7. public:
  8.     CFlatData(void* pbeginIn, void* pendIn) : pbegin((char*)pbeginIn), pend((char*)pendIn) { }
  9.     char* begin() { return pbegin; }
  10.     const char* begin() const { return pbegin; }
  11.     char* end() { return pend; }
  12.     const char* end() const { return pend; }
  13.  
  14.     unsigned int GetSerializeSize(int, int = 0) const
  15.     {
  16.         return pend - pbegin;
  17.     }
  18.  
  19.     template<typename Stream>
  20.     void Serialize(Stream& s, int, int = 0) const
  21.     {
  22.         s.write(pbegin, pend - pbegin);
  23.     }
  24.  
  25.     template<typename Stream>
  26.     void Unserialize(Stream& s, int, int = 0)
  27.     {
  28.         s.read(pbegin, pend - pbegin);
  29.     }
  30. };
cpp
运行

这是因为COutPoint类的数据结构，uint256 hash和unsigned int n;正好是 内存 四字节对齐，没有填充的数据，所以这里直接读取整个对象也没问题。而CFlatData专门用来处理这种类的序列化，它可以把这种类强制转换成CFlatData类对象，通过把一段数据的起始和结束地址作为参数。可以把它们伪装成CFlatData类，为什么要变成这个类呢？你可以看这个类有三个函数。serialize相关的三个函数，所以当转换成这个类后，就自带序列化功能了。不用再写
